# Skill: OpenSpec Validator

## Propósito
Validar que las especificaciones dentro de `openspec/specs/` cumplan con la estructura requerida antes de iniciar el desarrollo.

## Criterios de Validación
1. Debe incluir número de Issue de GitHub.
2. Debe listar explícitamente los requerimientos funcionales (`RF-XX`).
3. Debe contener el desglose de tareas asignadas a agentes (`Task Breakdown`).
4. Debe definir criterios de aceptación claros.
