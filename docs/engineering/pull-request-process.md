# Pull Request & Review Process

## 1. Flujo de Trabajo
1. Seleccionar o crear un Issue / OpenSpec.
2. Crear una rama siguiendo la convención (`feat/`, `fix/`, `chore/`, `docs/`).
3. Implementar cambios utilizando Claude Code y la suite de agentes.
4. Abrir Pull Request hacia `main`.
5. Pasar verificaciones del pipeline CI/CD en GitHub Actions.
6. **Aprobación Humana Explícita (Level 4 Autonomy).**
7. Merge a `main` y eliminación automática de la rama de trabajo.
