# GitHub Engineering Platform & Standards

## 1. Visión General
Esta plataforma utiliza GitHub como núcleo central de ingeniería para trazabilidad, control de calidad y gestión de cambios asistidos por IA.

## 2. Componentes Integrados
- **Golden Repository:** Estructura base estandarizada.
- **GitHub Projects:** Tablero de control (Backlog, Board, Roadmap).
- **Issue Templates:** User Stories, Bugs, Technical Debt y Security.
- **Pull Request Templates & CODEOWNERS:** Gobierno de cambios y asignación de revisores.
- **Rulesets:** Protección de la rama `main` exigiendo Pull Request y CI passing.
