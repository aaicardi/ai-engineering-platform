# Definition of Done (DoD)

Una funcionalidad o User Story se considera finalizada cuando:
- [ ] Código implementado siguiendo estándares.
- [ ] Pruebas unitarias/integración asociadas pasando.
- [ ] Especificación OpenSpec actualizada en `openspec/specs/`.
- [ ] Sin vulnerabilidades ni secretos en texto plano.
- [ ] Pipeline de CI/CD en GitHub Actions pasando en verde.
- [ ] Documentación actualizada.
- [ ] Aprobación humana del PR realizada.
